Pick a scale/key to auto-check matching notes, then scrub. The drone chord has its own key, so you can scrub a scale over a chord in a different key on purpose. The progression follows the scale's Key. Flip on Enable Beat for basic drums under the progression. Auto Scrub sweeps the slider one note per Note Length at the Tempo, bouncing back at each end; Go to Lowest Root jumps to the lowest unmuted note of the Key. Drag the Play Order tiles to change which note each spot on the slider plays, or pick a pattern from Ordering. The Barry Harris Chromatic orderings follow the Scale/Key (Major if none is picked): unmuted non-scale keys become chromatic passing tones, and where none is available the scale tone above is added (so a note can appear twice) to keep scale tones on the beat. Slur glides pitch continuously between notes instead of jumping (turns off Sustain, since they conflict). Quantize snaps scrubbed notes onto a rhythmic grid — set by Note Length and the Tempo field — instead of firing exactly when you cross a key; Sustain and Slur are locked off while it's on. Reverse Envelope swells each keyboard note up to full volume and cuts it off, instead of the normal pluck-and-decay. Delay only affects the keyboard channel.
